# 🧠 Smart MCQ Solver

This application predicts the **Top-3 answers** for multiple-choice questions using an **Artificial Neural Network (ANN)** trained on **TF-IDF features**.

## Features

- Predicts Top-3 answers
- Confidence scores
- Built with PyTorch
- Gradio interface
- Deployed on Hugging Face Spaces

## Model

- Artificial Neural Network (ANN)
- TF-IDF Vectorizer
- PyTorch
